## 五、需求详情

### 5.1 角色变更确认

| 维度 | 需求说明 |
| --- | --- |
| 用户与场景 | 团队管理员在修改高危角色时，需要确认影响并在校验失败后恢复操作。 |
| 需求入口 | 团队管理员在成员页提交高危角色变更时触发。 |
| 需求详情 | 一、角色变更流程<br>1. 同一确认弹窗展示角色变化、校验提示、取消操作和提交反馈。<br>2. 管理员确认后提交变更。<br>二、状态与反馈<br>1. 校验失败时保留当前选择并提示修正方式。<br>2. 提交完成后展示结果。 |
| 设计与交互 | 突出角色变化和主操作，取消操作始终可见，反馈在弹窗内连续呈现。 |
