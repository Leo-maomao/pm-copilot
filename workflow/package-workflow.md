# Package Workflow Compatibility Redirect

`workflow/package-workflow.md` is a legacy compatibility entry.
Use `workflow/delivery-check-workflow.md` for the current PM Copilot 3.0 delivery check workflow.

The old "package" name is kept so older prompts, adapters, or run logs that mention package validation still resolve.
New instructions should use "delivery check" instead of "package" because PM Copilot does more than bundle files: it verifies product usefulness, readiness, evidence, validation, and handoff consistency.

Legacy `pm-package.md` style outputs are not generated by default.
When a run needs final validation, call the Delivery Orchestrator:

```bash
python3 scripts/run_delivery_checks.py outputs/<run-id> --language <zh|en>
```
