# 项目 Git 归属映射

- 状态：已接受
- 日期：2026-09-11

## 决策

管理器允许用户重命名项目目录，但插件仍须依当前代码仓库的 Git `origin` 归属到同一项目。需求库在 `requirements/.manager/project-origins.json` 保存当前项目目录到原始 Git 归属的映射。映射仅是本机管理器元数据，不属于需求正文，也不对浏览者返回。

服务对项目重命名和删除使用 `.manager` 下的短生命周期事务日志；服务重启后会依据目录是否已经移动或删除来完成映射提交或撤销未开始的操作。插件以 Git `origin` 查询映射；无映射时仍直接使用仓库名或当前目录名。一个 Git 归属若映射到多个目录、映射损坏或映射目录不存在时拒绝写入，要求先在管理器中消除问题。
