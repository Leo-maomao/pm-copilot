# 浏览器编辑会话

- 状态：已接受
- 日期：2026-09-10

## 决策

管理器默认只读。用户点击管理器标题并输入本机编辑口令后，服务为当前浏览器签发持久的 HttpOnly Cookie；只有携带有效会话的写请求被接受。令牌写入 Git 忽略的 `requirements/.manager/editor-sessions.json`，服务重启后仍有效。Cookie 的 10 年有效期是浏览器实现持久 Cookie 所需的技术上限，在本工具的单人使用场景中等同于永久有效。

## 后果

产品可通过局域网地址使用编辑能力，其他浏览器不会因访问来源相同而获得写权限。该机制适用于可信局域网的轻量保护，不替代多人账号或审计系统；删除该本机令牌文件即可让所有浏览器重新进入只读状态。
