# 正文使用安全 Markdown 渲染

- 状态：已接受
- 日期：2026-09-10

## 背景

需求详情以 Markdown 保存，直接显示纯文本会丢失表格、列表和文本层级。内容又来自本机项目，不能将 Markdown 或嵌入 HTML 原样作为可执行页面内容。

## 决策

管理页使用 `marked` 将需求正文转换为 HTML，再使用 `DOMPurify` 清洗后渲染。图示继续走受限的本机图示 API，不从 Markdown HTML 中加载任意资源。

## 后果

正文可呈现 Markdown 的结构化排版，同时脚本、事件属性和不安全的嵌入内容会被清除。此渲染只影响展示层，不改变原始 Markdown 文件。
