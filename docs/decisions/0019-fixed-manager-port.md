# 固定管理器服务端口

- 状态：已接受
- 日期：2026-09-11

## 背景

需求管理器作为本机与可信局域网的固定入口，需要稳定 URL。运行时允许通过环境变量改写监听端口会造成启动器、书签和局域网访问地址不一致，也可能让旧服务占据默认端口而不易发现。

## 决策

常规服务固定监听 `0.0.0.0:57391`，忽略 `PM_COPILOT_PORT`。只有 `NODE_ENV=test` 的自动化测试进程可通过该变量取得临时隔离端口。

## 后果

管理器始终可通过固定端口访问；启动器重启后不会因遗留端口配置产生不同 URL。测试仍能并行于常规服务启动，不占用用户正在使用的端口。
