# 管理器采用纯前端运行时

- 状态：已替代，见 `0006-local-index-service.md` 与 `0009-local-only-status-writes.md`
- 日期：2026-09-09

## 背景

需求管理器是纯前端工具，不应为了展示需求状态而依赖 Fastify、HTTP API 或常驻本地服务。

## 决策

移除本地服务工作区、Fastify、Zod、HTTP 健康检查和 Vite API 代理。管理页在浏览器中直接使用 `packages/core` 的前端数据源。开发时仅运行 Vite，固定监听 `0.0.0.0:57391`。

## 后果

页面不会显示服务连接错误，也不需要服务端口。浏览器无法直接任意读取仓库文件；未来引入 Markdown 需求文件时，必须先通过 ADR 决定由 Codex 插件导入、浏览器文件选择器导入或构建期打包哪一种方式，不能暗中恢复 HTTP 服务。
