# 架构概览

```text
plugins/pm-copilot -> requirements/
apps/manager-web -> services/local-server -> packages/core
```

插件从目标项目读取代码与可选本地页面，正式输出只写入统一需求库。管理页只访问同源服务；服务提供集中索引、受控资产读取和编辑会话保护的写接口。`packages/core` 不依赖浏览器或文件系统。`requirements/` 不提交，不使用数据库、云同步或遥测。

索引在每次读取时从磁盘重建：插件直接写文件，不经过服务端，因此读取必须反映磁盘真实状态，页面刷新即可看到新需求。重建在内存中完成后一次性换入并串行执行，读取方不会看到半成品索引；当前库量级下每次重建约十几毫秒。`POST /api/refresh` 保留为等价的显式重建入口。

服务固定监听 `0.0.0.0:57391` 供可信局域网阅读，常规运行不接受其他端口；测试进程才可使用隔离端口。写请求需要当前浏览器完成编辑口令解锁，解锁令牌持久保存在 Git 忽略的本机需求库中，公开接口不返回本机路径。
